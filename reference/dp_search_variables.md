# Search D-PLACE variables by keyword

A thin, more discoverable wrapper around \`dp_variables(search =
keyword)\`.

## Usage

``` r
dp_search_variables(keyword, type = NULL)
```

## Arguments

- keyword:

  A search term matched (case-insensitively) against variable names and
  descriptions.

- type:

  Optional character vector restricting to variable type(s):
  \`"Categorical"\`, \`"Ordinal"\`, and/or \`"Continuous"\`. Does not
  support \[contains()\]. Passed straight to \[dp_variables()\].

## Value

A tibble of matching variables (see \[dplace_variables\] for column
definitions).
